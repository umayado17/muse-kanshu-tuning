# muse-kanshu-tuning ― Muse を慣習法的にチューニングするインストラクション

パーソナルエージェント Muse の運用を「慣習法的」な形に整えるための、貼って使う指示文です。

ここで「慣習法的」とは次の様式を指します。最初から矛盾のない一つの規則集を作るのではなく、出自の違う決まりと経験を層に分けて残し、食い違いは優先順位で実行時に裁く。判断の蓄積を、理由付きの先例として次の判断に使う。

## 使い方

[`Muse慣習法的チューニング_汎用インストラクション.md`](Muse慣習法的チューニング_汎用インストラクション.md) の「Muse への指示」を、そのまま Muse に貼ってください。Muse はいまのファイル（AGENTS.md、GOAL.md、スキル、MEMORY.md）を読み、変更案を見せてきます。書き込むのは、あなたが承認してからです。

## 五つの項目

1. 正本と運用知を分け、統合しない
2. 判断は「理由付きの先例」として残し、外し方・覆し方を決めておく
3. 目標ごとに「レンズ」を持ち、レンズで探す
4. 会話の場を AIR.md で引き継ぐ
5. 蓄積を、持ち出せる形で残す
